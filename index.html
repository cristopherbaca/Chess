How to start the API
  1. First, open vendor/train.ipynb in a GPU Colab runtime and choose Run all. It trains and saves the champion to Drive automatically.
  2. Open vendor/deploy.ipynb in another Colab runtime and choose Run all. It only deploys the saved model and finishes with a verified HTTPS URL.
  3. Paste that URL here, enable Use AI server, and press Test connection.
  4. Keep the deployment runtime connected while playing. Run all again and paste the new URL when restarting deployment.

The web page cannot start Colab. The offline bot plays random legal moves without any API. A localhost server runs on your computer, not in Colab.
